برج الإنارة V4 — نسخة متجاوبة للجوال (Android و iOS)

للمعاينة على الكمبيوتر: افتح index.html.
للمعاينة على الجوال: انشر الملفات على GitHub Pages عبر HTTPS ثم افتح الرابط في Chrome على Android أو Safari على iPhone.
لتثبيت تطبيق الويب: على Android استخدم تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية؛ وعلى iPhone استخدم مشاركة > إضافة إلى الشاشة الرئيسية.
تفعيل التخزين المؤقت وخاصية PWA يتطلب استضافة HTTPS أو localhost؛ فتح الملف مباشرة لا يفعّل هذه المزايا.
هذا نموذج تجريبي وليس تطبيقاً أصلياً ولا متجر دفع حقيقي. الصور والأسعار استرشادية.

برج الإنارة — Smart Industrial V5
نموذج تجريبي من عولق تك، ليس متجراً حقيقياً ولا يستقبل طلبات أو مدفوعات.

التشغيل محلياً:
1. فك الضغط.
2. افتح index.html في Chrome أو Edge.
3. اضغط مفتاح الإنارة ثم جرّب البحث والتصنيفات والسلة وتجربة الضوء.

النشر على GitHub Pages:
1. افتح مستودع burj-alenara-store في GitHub.
2. من Add file اختر Upload files.
3. ارفع جميع الملفات والمجلد assets من داخل مجلد Burj-AlEnara-V5 مباشرة إلى جذر المستودع.
4. وافق على استبدال الملفات القديمة ذات الأسماء المتطابقة، ثم Commit changes.
5. تأكد أن Settings > Pages يختار main و /(root).
6. انتظر اكتمال النشر ثم افتح رابط موقعك، وقد تحتاج إلى تحديث قوي أو فتح نافذة خاصة لتجاوز التخزين المؤقت.

مهم: احتفظ بنسخة احتياطية من V4 قبل الاستبدال. صور المنتجات الست توضيحية مُولّدة وليست صوراً موثقة لمنتجات حقيقية، وبعضها مستخدم لأكثر من منتج. جميع الأسعار تجريبية وتحتاج تحققاً قبل الاستخدام التجاري. التفاعلات ثلاثية الأبعاد هي محاكاة CSS وليست نماذج WebGL هندسية.

برج الإنارة | النسخة السينمائية V3

طريقة التشغيل:
1. فك الضغط.
2. افتح index.html في Chrome أو Edge.
3. اضغط على مفتاح الإنارة الجداري لتشغيل التجربة.
4. تصفح المنتجات واضغط «معاينة» للتكبير، واختبر البحث والتصنيفات والسلة.

هذه نسخة تجريبية من عولق تك وليست متجراً جاهزاً لاستقبال المدفوعات.
الصور التوضيحية مولدة رقمياً، وقد تتكرر بين المنتجات ولا تثبت موديلات فعلية.
الأسعار استرشادية وليست تسعيراً محدثاً أو عروضاً تجارية.
الواجهة تستخدم CSS 3D وطبقات ضوء وتفاعلات، وليست نماذج WebGL ثلاثية الأبعاد هندسية كاملة.
تعمل دون خادم، لكن خط Cairo يحتاج الإنترنت عند أول تحميل.
